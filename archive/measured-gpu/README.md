# Sources used for recorded GPU measurements

These original source files are preserved because current robustness fixes change their hashes. The original manifest remains unchanged; `archive/path-map.json` resolves its paths to these bytes. Other manifest entries still resolve to unchanged active sources or the language-model archive.

The recorded timing conclusions apply to the original measured implementation, not a new performance measurement of the current fixes. This directory is evidence, not an importable alternative package.
