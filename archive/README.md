# Archive

[language-model](language-model/README.md) preserves the earlier neural language-model experiment, its source, training tools, tests, synthetic corpus, configs, and measured results. It is separate from the active lossless storage and computation-reuse package.

`path-map.json` records every relocation. The GPU evidence verifier uses it to locate original frozen source bytes without rewriting the original manifest or measurements. Earlier representation and GPU reports remain linked from [the experiment trail](../docs/EXPERIMENT_TRAIL.md).
