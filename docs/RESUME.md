# Resume description

**Structural Residual Language Model — Independent Research Prototype**

Built a deterministic structural encoder and context-trie prior, integrated observed-token residuals with a small neural language model, and evaluated conditional computation using reproducible benchmarks and 14 ablation conditions across three seeds. Instrumented prediction quality, actual optional-block execution, process memory and end-to-end throughput; documented structural overhead that prevented a practical speedup.

Do not describe this smoke-corpus result as a faster production language model or as validated on natural-language benchmarks. Historical ideas belong to Dustin; the current code was implemented with AI assistance and records implementation choices separately in provenance.
